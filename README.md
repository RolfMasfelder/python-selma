## 🌟 Overview

**Agent Selma** is a simplified, educational version of the [OpenClaw](https://github.com/openclaw/openclaw) project.

The primary goal of this project is to deconstruct and understand the underlying architecture of autonomous agents by rebuilding them from scratch using **Python** and **Pydantic AI**. By stripping away complexity, Selma serves as a clean baseline for learning how agentic components interact.


## 🛠 Tech Stack

  * **Language:** [Python](https://www.python.org/)
  * **Framework:** [Pydantic AI](https://ai.pydantic.dev/) (for type-safe, structured model interactions)
  * **Inspiration:** [OpenClaw](https://github.com/openclaw/openclaw)/[PI-Agent](hhttps://github.com/badlogic/pi-mono)
